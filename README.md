# RELO-MATE

RELO-MATE is a source-grounded relocation checklist assistant demo built with
Next.js App Router. The demo supports two student journeys:

- Indonesia → Taiwan
- Poland → Vietnam

NVIDIA AI rewrites the checklist in the user's selected language while
legal-sensitive fields remain anchored to each verified source pack.

The result page also includes a lightweight RAG document chatbot. It retrieves
case-scoped curated excerpts from the official source pack, asks NVIDIA to
answer only from those excerpts, and returns clickable citations. No vector
database is required for the two-case demo.

## Run Locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## NVIDIA AI Mode

Copy `.env.example` to `.env.local`:

```bash
AI_MODE=nvidia
NVIDIA_API_KEY=your_server_side_key
NVIDIA_BASE_URL=https://integrate.api.nvidia.com/v1
NVIDIA_MODEL=meta/llama-3.2-3b-instruct
NVIDIA_TIMEOUT_MS=90000
```

Restart `npm run dev` after changing any environment value. Next.js reads
`.env.local` when the server starts.

The NVIDIA key is read only by the server-side App Router route handler. It is
never sent to the browser. The result page displays **Generated by NVIDIA AI**
when generation succeeds.

## Safe Fallback Behavior

- `AI_MODE=mock` returns the source-grounded mock plan.
- Missing `NVIDIA_API_KEY` returns the mock plan.
- NVIDIA timeout, upstream error, invalid JSON, or unsafe checklist structure
  returns the complete plan with `generatedBy: "mock-fallback"`.
- Visa type, documents, timeline, source links, and disclaimer always remain
  anchored to the supported source case.
- RAG chat failures return the most relevant retrieved source notes with
  `generatedBy: "mock-fallback"` instead of leaving the chat unusable.

## Troubleshooting

**The result says “Demo fallback plan”**

1. Confirm `.env.local` contains `AI_MODE=nvidia`.
2. Confirm `NVIDIA_API_KEY` and `NVIDIA_MODEL` are populated.
3. Keep `NVIDIA_BASE_URL` at `https://integrate.api.nvidia.com/v1`.
4. Restart the Next.js dev server.
5. Check the terminal for a sanitized NVIDIA error message.

**Generation looks stuck or falls back after 30 seconds**

NVIDIA hosted endpoints can have variable queue latency. RELO-MATE defaults to
a 90-second server timeout and a 100-second browser timeout. It also caches a
successful NVIDIA result in the running server for 15 minutes, which makes
repeat presentation runs fast. The UI remains on the final loading step and
automatically falls back if the request fails or times out.

`NVIDIA_TIMEOUT_MS` accepts values from `10000` to `120000`. For presentation
reliability, `meta/llama-3.2-3b-instruct` is recommended over a 70B model.

## API

`POST /api/generate-checklist`

The route accepts either a direct profile object or `{ "profile": { ... } }`.
Only Indonesia → Taiwan → Study and Poland → Vietnam → Study are supported in
this demo. Preferred languages are English, Bahasa Indonesia, Traditional
Chinese, Polish, and Vietnamese.

`POST /api/chat`

The RAG route accepts `{ "profile": { ... }, "question": "..." }`. Retrieval is
restricted to the selected supported case, and every generated answer includes
the official source excerpts and links used to answer.
